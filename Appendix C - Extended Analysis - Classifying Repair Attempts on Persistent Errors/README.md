# Appendix C: Extended Analysis: Classifying Repair Attempts on Persistent Errors

This folder supports Appendix C of the paper. It contains the event-level data, the analysis script, and the saved outputs used to verify the persistent-error transition analysis.

## Files

- `data/exact_signature_transition_analysis.csv`
- `appendix_c_persistent_error_analysis.py`
- `appendix_c_stats_output.txt`
- `results/summary_transition_states.csv`
- `results/summary_persistent_transition_outcomes.csv`

## Coverage

- C.1 Error transition outcome explanations
- C.2 Persistent error analysis

## Prerequisites

- Python 3.10+

## Run

From the repository root:

```bash
python3 'Appendix C - Extended Analysis - Classifying Repair Attempts on Persistent Errors/appendix_c_persistent_error_analysis.py' > 'Appendix C - Extended Analysis - Classifying Repair Attempts on Persistent Errors/appendix_c_stats_output.txt'
```
